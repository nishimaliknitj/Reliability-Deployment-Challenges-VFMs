## Overview

This repository accompanies our survey paper:

**Reliability and Deployment Challenges of Visual Foundation Models in Visual Computing: A Task-Centric Survey**

The repository contains:

- Survey manuscript
- Supplementary material
- Reproducibility resources
- Taxonomy documentation
- Benchmark references
- Future data releases

## Repository Structure

paper/      → Manuscript and supplementary material
data/       → Structured benchmark and annotation resources
docs/       → Methodology and reproducibility documents
figures/    → Figures used in the manuscript
scripts/    → Utility scripts

## Benchmark Resources

The repository provides:

- benchmark_master.csv
- literature_corpus.csv
- weakness_annotations.csv

These resources consolidate benchmark results, literature metadata, and reliability challenges discussed throughout the survey.
